## 📌 Présentation & Objectifs

Ce portfolio a été conçu sur-mesure pour **Nourou LY**, professionnel en **Géomatique et Sciences de l'Information Géographique**, afin de présenter de manière rigoureuse et interactive l'ensemble de ses compétences techniques, projets spatiaux, missions de terrain et productions cartographiques.

### Modules inclus :
1. **Accueil & Profil** : Synthèse de parcours, disponibilité, coordonnées professionnelles et téléchargement direct du CV en PDF.
2. **Projets SIG & Géomatique** : Fiches projets détaillées (contexte, objectifs, méthodologie spatiale, jeux de données, résultats et visualisations cartographiques).
3. **Cartothèque Thématique** : Galerie haute résolution de cartes avec modal d'affichage plein écran, zoom, projections et métadonnées sémiologiques.
4. **Missions de Terrain & GNSS** : Journal d'interventions de terrain, protocoles de levés GPS/GNSS, matériels utilisés et photographies géo-référencées.
5. **Compétences Techniques** : Matrice de compétences (SIG bureautique, WebSIG, bases de données spatiales, télédétection, programmation Python/R).
6. **Parcours & Diplômes** : Formations académiques et expériences professionnelles avec pièces justificatives.
7. **Formulaire de Contact** : Formulaire fonctionnel pour les recruteurs et partenaires avec validation en direct.
8. **Espace Administration (CMS intégré)** : Gestion autonome de 100% des contenus avec sélecteur de fichiers automatique (redimensionnement et compression automatique des photos et documents côté client).

---

## 🛠️ Stack Technique

- **Frontend** : React 18, TypeScript, Tailwind CSS, Lucide React Icons
- **Backend / Serveur** : Node.js, Express, TSX, Vite Middleware
- **Stockage & Persistance** : Fichier JSON structuré avec API REST d'administration sécurisée par jeton Bearer
- **Gestion des Médias** : Compression client intelligente via HTML5 Canvas (traitement instantané des photos smartphone en HD légère)

## 🚀 Installation & Lancement en local

### Prérequis
- [Node.js](https://nodejs.org/) (version 18 ou supérieure)
- npm ou yarn

### 1. Cloner le dépôt
```bash
git clone https://github.com/lynourou/Nourou_LY_fr_Portfolio_cv.git
cd Nourou_LY_fr_Portfolio_cv
```

### 2. Installer les dépendances
```bash
npm install
```

### 3. Démarrer en mode développement
```bash
npm run dev
```
L'application est accessible sur [http://localhost:3000](http://localhost:3000).

### 4. Compiler pour la production
```bash
npm run build
npm start
```
