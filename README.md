## 📌 Présentation & Domaines d'Expertise

Ce portfolio a été conçu sur-mesure pour **Nourou LY**, technicien supérieur et spécialiste en **Géomatique, Télédétection et Analyse Spatiale**, afin de présenter avec rigueur méthodologique l'ensemble de ses compétences, projets, travaux de terrain et publications académiques.

### Modules inclus :

1. **Accueil & Profil** : Présentation du profil professionnel, disponibilité, compétences clés et téléchargement instantané du CV en PDF.
2. **À propos & Parcours** : Frise chronologique retraçant l'évolution technique (métallurgie et mécanique → géomatique → SIG, télédétection et gestion forestière).
3. **Compétences Techniques** : Matrice dynamique (SIG bureautique QGIS/ArcGIS, traitement d'images Sentinel-2/Landsat, bases de données spatiales PostgreSQL/PostGIS, collecte terrain QField/GPS RTK, Webmapping).
4. **Projets SIG Détaillés** : Fiches projets complètes avec problématique, objectifs, méthodologie spatiale, indices spectraux (EVI, MNDWI, BSI), captures et conclusions.
5. **Expériences Professionnelles** : Postes occupés (Direction des Eaux et Forêts DEFCCS, Mastercom, etc.) avec missions détaillées.
6. **Missions de Terrain** : Protocoles in situ, levés topographiques GNSS, arpentage et géo-référencement.
7. **Cartothèque Thématique** : Galerie haute résolution de cartes avec métadonnées sémiologiques, échelle, système de projection et zoom interactif.
8. **Cursus & Diplômes** : Formations académiques supérieures (BTS Géomatique au CEDT Le G15, etc.).
9. **Documents & Mémoires** : Section dédiée pour consulter et télécharger les travaux académiques, notamment le **Mémoire de fin d'études BTS Géomatique (136 pages) : *« Apport de la géomatique à la gestion de la forêt classée de Mbao »***.
10. **Contact & Fiche vCard / QR Code** : Coordonnées directes, intégration LinkedIn et génération de carte de visite numérique.
11. **Espace d'Administration Sécurisé (#admin)** :
    - Gestion autonome de l'ensemble des contenus.
    - Synchronisation en 1 clic vers GitHub Pages sans terminal ni manipulation de fichier ZIP.
    - Système d'alerte visiteur par email (Formspree) ou Webhook (Discord/Slack/Telegram).

## 🛠️ Stack Technique

- **Frontend** : React 19, TypeScript, Tailwind CSS v4, Lucide React Icons
- **Hébergement & Déploiement** : GitHub Pages (racine `/docs` avec support SPA et redirection `.nojekyll`)
- **Synchronisation API** : API REST GitHub (mises à jour directes en 1 clic via Personal Access Token)
- **Persistance des Données** : Stockage hybride (IndexedDB haute capacité + `docs/portfolio-data.json`)
- **Sécurité** : Authentification SHA-256 via Web Crypto API native
- **Visualisation & Cartographie** : Intégration SIG interactive et lecteur haute fidélité pour documents PDF

## 🚀 Installation & Développement Local

### Prérequis
- [Node.js](https://nodejs.org/) (version 18 ou supérieure)
- npm ou yarn

### 1. Cloner le dépôt
```bash
git clone https://github.com/lynourou/Nourou_LY_fr_Portfolio_cv.git
cd Nourou_LY_fr_Portfolio_cv
```

### 2. Installer les dépendances
```bash
npm install
```

### 3. Lancer le serveur de développement
```bash
npm run dev
```
L'application est accessible en local sur `http://localhost:3000`.

### 4. Compiler pour GitHub Pages
```bash
npm run build
```
La compilation génère automatiquement les fichiers de production dans le dossier `docs/` prêt pour GitHub Pages.
